Empowering Citizens, Streamlining Governance

📌 Project Overview
NagariMitra is an AI-powered, multilingual grievance redressal system designed to bridge the gap between citizens and municipal authorities. By leveraging WhatsApp as a primary interface, it allows users to report urban issues (like potholes, garbage, or water disruptions) using text, voice, or images.

🛠️ The Prototype Features
Currently, the prototype demonstrates the following core workflows:

Multimodal Input: Support for reporting issues via text and image.

AI-Driven Analysis: Basic NLP for complaint categorization and priority detection.

Officer Dashboard: A centralized view for municipal officers to track and manage incoming reports.

Geo-Location Mapping: Preliminary integration for pinning complaint locations.

🚀 Upcoming Improvements (In Progress)
We are currently in a high-activity development phase. Expected updates in the coming days include:

Voice Integration: Refining multilingual voice-to-text processing.

Advanced AI Vision: Improving image detection for automatic validation of reported issues.

Duplicate Filtering: Logic to prevent multiple reports for the same incident.

Real-time WhatsApp Webhooks: Finalizing the integration for a seamless chat experience.

💻 Tech Stack
Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

AI/ML: NLP for language processing and Computer Vision for image analysis.

⚙️ Installation (For Local Testing)
Clone the repo:

Bash
git clone https://github.com/dnyana21/SmartCity_Prototype.git
Install Backend Dependencies:

Bash
cd backend && npm install
Install Frontend Dependencies:

Bash
cd frontend && npm install
Environment Variables: Create a .env file in the backend folder and add your MONGODB_URI and PORT.
